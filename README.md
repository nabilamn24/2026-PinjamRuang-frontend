# 🏢 PinjamRuang App

Aplikasi peminjaman ruangan kampus berbasis web.
Project ini dibuat untuk memenuhi Tugas PBL Semester 3.

## 🚀 Tech Stack

- **Frontend:** React + Vite + Bootstrap
- **Backend:** ASP.NET Core Web API 8.0
- **Database:** SQL Server

## ⚙️ Cara Menjalankan Project

### Backend

1. Masuk ke folder backend.
2. Jalankan perintah: `dotnet run`
3. Server berjalan di: `http://localhost:5043`

### Frontend

1. Masuk ke folder frontend.
2. Install dependencies (pertama kali): `npm install`
3. Jalankan perintah: `npm run dev`
4. Buka browser: `http://localhost:5173`
